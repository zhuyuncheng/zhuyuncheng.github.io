# 旅行执行台完整优化计划

1. 统一路线编译与多次到访同一地点的完成状态。
2. 午餐/晚餐独立主选和备用，指定路线插入位置，替换同步地图、试算、今天与总方案。
3. 候选支持高德路线校核，失败保留同口径粗估，采用前不修改方案。
4. 连住酒店与每日餐饮/门票/补能/停车/高速/其他费用汇总；缺失报价不是零元。
5. 预订清单、预约时间、取消期限、上海时区日历导出。
6. 完成状态撤销；停车文字记忆只在本机。
7. 独立 HTML 离线行程册，内嵌地点图片与样式；不依赖全站 Service Worker。
8. 构建、自动测试、桌面手机交互验收后完整交付。

营业时间、价格、充电枪位仍需复核；不自动下单。地图和实时算路需联网。
验收覆盖：餐饮切换、重复地点独立完成、酒店跨日更新、预约取消日历、未知费用、旧状态兼容、离线无外链依赖、320/390/1024/1440 布局。
