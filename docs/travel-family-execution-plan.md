# 家庭出行体验五项执行计划

1. 微信家庭卡：新增独立只读页面；全程 / 单日快照链接、PNG 海报、系统分享及复制降级。共享内容只含公开 POI ID、日期和出发时间，不含住址输入、日记、订单、费用或完成状态。分享不是实时同步，不承诺微信原生分享卡片标题 / 缩略图。
2. 想去清单：景点收藏，按候选所属日和几何绕行推荐日期，列出现有重复、新增时间及超量风险；先预览，再添加，不自动删除已有地点。
3. 玩法分层：地点抽屉提供 30 / 90 / 深入游玩时间预算、宝宝参与方式、家庭影像主题与取舍；只对已安排日期应用停留时长，不擅自改选景点。短版不表示完整游览或低价门票。
4. 饭点推荐：围绕实际前后停靠点排序，可按少绕路 / 本地菜 / 宝宝主食 / 停车资料查看；具体点单来自原候选资料。未核验停车与儿童椅不产生虚假的评分；预览路线变化后选择午餐或晚餐。
5. 酒店双模式：同一酒店连续入住日可预览午餐后回房的真实停靠点，和白天不回房方案比较；入住 / 退房日不默认可用房。休息地点未知明确标示。

顺序：状态与纯函数 → 微信只读卡 → 清单 / 排日 → 玩法 → 饭点 → 酒店双模式 → 自动测试 / 构建 / 浏览器验收。

验收：不破坏既有样式，旧数据兼容；预览不改变状态，确认后刷新保留；分享数据白名单及损坏链接降级；回酒店必须出现在实际路线，休息不重复计时；海报可保存，微信客户端行为需真机确认。
