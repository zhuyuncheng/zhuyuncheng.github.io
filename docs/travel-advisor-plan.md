# 候选与日程决策建设 · 2026-09-14

## 范围与入口

1. 路线编排 → 并排比较候选：景点、餐厅、充电、酒店的图文、带娃、时间、停车及取舍；几何插入比较明确标为粗估，已在路线中的点不重复计算。
2. 路线编排 → 预览轻松 / 标准 / 丰富版：7 个主要游玩日共 21 套组合；先看增加、移除、全日耗时与路线，确认后才采用。团圆与纯整备日不强行增加景点。酒店、补能保留；两餐主选替换、备用重新设置；手动排序恢复推荐。
3. 地点详情 → 停车：最后一公里指南，展示入口候选、步行 / 推车、游览、厕所、离场、夜间短走及停车搜索。未核实步行距离和车行入口不填写数值；已有地址不冒充已核实入口。
4. 我的方案 → 住宿基地：6 家酒店，比较连住报价、关联日路线与首个景点回房往返参考；提供酒店到主景点的高德查询链接、7 项入住确认清单。换酒店需要确认，自动覆盖关联日、修正餐厅插入锚点，不覆盖其他城市酒店。
