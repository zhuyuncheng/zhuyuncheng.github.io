# 旅行执行台后续建设

## 交付顺序

1. 行程试算：当天出发时间、游玩与停车缓冲、逐站电量区间、午睡和晚餐冲突提示。真实算路与估算明确区分，参数随方案保存。
2. 候选对比：在采用前比较路线、时间和费用变化；保留手动顺序，支持取消预览。
3. 餐饮与酒店联动：午晚餐独立选择、附近备用、跨日住宿总价和回房成本。缺失数据先核验，不生成虚假营业时间或价格。
4. 行前工具：预订状态、日历导出、完成状态撤销、停车记忆。
5. 离线：缓存静态行程与已查看图片；标明在线导航边界，验证更新与清理缓存。

## 验收原则

- 延用现有页面，新增样式限定在旅行页。
- 改出发时间、顺序和选择后试算同步更新，刷新和导入后参数保留。
- 无高德结果时标记估算，充电时长与目标电量由用户确认。
- 每阶段构建与功能检查后本地交付；最终联动功能完成后部署验收。
